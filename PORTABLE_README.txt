MD Viewer Tauri Portable

Contents:
- md-viewer-tauri.exe

Usage:
- Unzip the package to any folder you can write to.
- Run md-viewer-tauri.exe directly.

Notes:
- This portable version does not install itself into Windows.
- It does not create Control Panel uninstall entries.
- It does not set itself as the default app for .md files.
- On Windows, Tauri uses the system WebView2 runtime. Most managed Windows 11 systems already have it.
